操作说明

机场订阅的核心是「购买或续费 → 拿到订阅地址 → 导入客户端 → 选择节点连接」。快柠檬不在正文放置来路不明的安装包地址，客户端请使用本页下载模块。

  1. 阅读套餐差异先看流量、同时在线设备与服务边界，再下单。不要只看月费数字。
  2. 获取订阅链接在用户中心复制订阅地址，妥善保存，避免发到公开群组。
  3. 安装客户端按系统选择对应客户端。导入方式以该客户端文档为准，一般为订阅 URL 或二维码。
  4. 更新并连接导入后先更新节点列表，再选择延迟可接受的线路连接。连不上时先检查系统时间、订阅是否过期、是否超出设备数。
  5. 日常维护流量将近用尽、客户端报错或需要换设备时，回到套餐与常见问题两节对照处理，而不是反复重装。

常见问题

这是本页的重点阅读区。把快柠檬当成机场来用时，大多数卡点都出现在订阅导入、设备数量和流量周期，而不是口号。

快柠檬是什么？和普通 VPN 有何不同？

快柠檬按机场订阅模式提供网络加速：你购买套餐后获得可导入客户端的订阅，而不是安装一个写死线路的单一 App。VPN 一词常被用来泛指加密隧道；机场更强调可更换的节点池与可更新的订阅。两者目标相近，交付方式不同。

没有技术背景，怎样完成第一次连接？

按「选套餐 → 复制订阅 → 下载客户端 → 导入 → 更新节点 → 连接」的顺序即可。第一次建议在电脑上操作，确认能打开目标网站后，再用同一订阅给手机导入。遇到导入失败，优先检查链接是否完整复制、客户端是否支持该订阅格式。

快柠檬支持哪些设备？

以你所选套餐允许的同时在线台数为上限，常见是桌面系统与移动系统搭配使用。具体可安装的客户端以下载模块列出的条目为准。不要在未列出的破解修改版里填入订阅，以免凭证泄露。

订阅链接能分享给同事或家人吗？

可以在套餐设备额度内给自己的设备使用，但不建议把链接发到公开频道。链接等于访问凭证，泄露后可能被他人耗尽流量或挤占设备数。团队场景请直接对照团队向套餐，而不是把个人订阅反复转发。

连上以后仍然打不开某些网站，怎么办？

先确认客户端真的处于已连接状态，再更换一条线路并清除浏览器缓存后重试。部分站点对数据中心 IP 更敏感，这与套餐是否写明对应能力有关。本页没有节点实测表，因此不要把一次失败理解成“服务全面不可用”。

流量或有效期如何理解？

流量与计费周期以套餐模块和用户中心账单为准。用尽后通常需要等待重置或升级套餐，而不是反复开关客户端。年付与月付只影响结算节奏，不自动改变单月额度规则，除非套餐文案另有说明。

客户端下载是否必须走快柠檬官网？

应当使用本页提供的下载入口或各客户端项目自己的发布渠道，避免搜索引擎广告页里的“加速器破解版”。官网在这里的意义是把订阅说明和下载入口放在一起，减少点错包、填错订阅的情况。

工单或客服怎样用才有效？

反馈时请写清操作系统、客户端名称与版本、发生时间、是否已更新订阅，以及报错原文。只说“不能用”很难定位。若套餐含优先支持，把订单号一并提供；不含则按普通工单排队，不要重复开单。
